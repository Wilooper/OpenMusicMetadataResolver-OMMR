# Code licensing and source attribution

[Docs](../README.md) · [SponsorBlock](../SPONSORBLOCK.md)

## Repository code

At this documentation revision, there is no root `LICENSE` file. Earlier README
and contribution text referred to MIT without providing that grant. Those claims
have been removed. The maintainer needs to choose and add a code license; these
docs do not select one on their behalf. A dependency's or vendored template's
license does not license OMMR's own code.

## Returned metadata

Provider metadata and datasets have their own terms independently of the eventual
code license. Preserve returned source attribution and license references. In
particular:

- SponsorBlock API/database data uses **CC BY-NC-SA 4.0** unless separately authorized.
  Its annotation includes the source URL, attribution, license and license URL.
- Wikipedia-derived biographies/context may include attribution/license information;
  retain it when displaying or redistributing that text.
- AcoustID's free lookup service has a noncommercial condition; an application key
  and client-generated fingerprint are required.
- Other APIs and catalog providers can impose access, caching, redistribution and
  account conditions. Enabling a provider does not remove them.

A source-specific preview URL does not grant rights to download, rehost or
redistribute audio. OMMR's highlight annotations do not supply audio.
